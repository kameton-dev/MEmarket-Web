# Скачивание приложений с клиентов MEmarket

В зависимости от клиента, приложения скачиваются по разному:

---

## MEmarket Silverlight

Приложение можно скачать, нажав на кнопку "установить" внизу экрана.

> **ВНИМАНИЕ!**
> Установщик может быть нестабильным и не устанавливать приложения. Если приложение завершило развертывание с ошибкой, попробуйте сохранить пакет, нажав на кнопку "соранить", и попробовать установить через ПК / CMD Injetor

---

## MEmarket UWP

Приложение можно скачать, нажав на кнопку "Установить". Потом, благодаря установленному пакету `Microsoft.App.Installer.v2019.1019.1.0.appxbundle`, после скачивания в диалоговом окне вы можете выбрать **"Установщик приложений"** и установить скачанный пакет на телефон.

> **Важное уточнение!**
> Установщик приложений не поддерживает установку XAP пакетов. В клиенте это предусмотренно, и прип опытке скачивания может вылезти диалоговое окно с предложением сохранить файл на устройство, для дальнейшего развертывания в CMD Injector / WPADT8.1
